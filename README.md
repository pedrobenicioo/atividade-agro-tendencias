# atividade-agro-tendencias

Aplicação Streamlit de Recuperação de Informação (RI) sobre PDFs de documentos agrícolas (soja, irrigação, controle biológico, adubação verde, lagartas desfolhadoras).

## Como executar

```
pip install -r requirements.txt
streamlit run aula.py
```
